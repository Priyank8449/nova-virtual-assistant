# 🤖 Nova - Voice-Controlled Virtual Assistant

Nova is a browser-based **Voice-Controlled Virtual Assistant** built using **HTML, CSS, and JavaScript**. It allows users to perform everyday tasks through simple voice commands, making browsing faster, hands-free, and more productive.

Instead of typing or searching manually, users can simply speak commands, and Nova responds with voice while instantly performing the requested action.

## ✨ Features

- 🎙️ Voice Command Recognition
- 🔊 Voice Responses using Text-to-Speech
- ⚡ Hands-Free Interaction
- 🌐 Open popular websites with a single command
- 🚀 Improves productivity and multitasking
- 💻 Lightweight and built with pure HTML, CSS & JavaScript
- 📱 Responsive and user-friendly interface

## 🎯 Supported Voice Commands

Nova can recognize commands such as:

- "Open YouTube"
- "Open WhatsApp"
- "Open LinkedIn"
- "Open GitHub"
- "Open LeetCode"
- "Open Google"
- "Open Gmail"
- "Open Calculator"
- "What is the time?"
- "What is today's date?"
- "Search for React tutorials"
- "Search JavaScript interview questions"

## 💡 Benefits

- Saves time by reducing manual navigation.
- Makes everyday tasks faster and easier.
- Enables hands-free browsing.
- Improves multitasking while working or studying.
- Provides instant voice feedback for every command.
- Enhances user productivity with simple voice interactions.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Web Speech API (Speech Recognition)
- Speech Synthesis API (Text-to-Speech)

## 🚀 How It Works

1. Click the microphone button.
2. Speak a command.
3. Nova recognizes your speech using the Web Speech API.
4. It processes the command.
5. Nova responds with voice.
6. The requested website or action is executed instantly.
